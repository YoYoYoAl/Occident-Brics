# Sons Occident vs BRICS : licences

Tous les fichiers de ce dossier sont sous licence **CC0 1.0 (domaine public)** :
https://creativecommons.org/publicdomain/zero/1.0/
Aucune attribution n'est exigée. Les auteurs sont tout de même crédités (bonne pratique, écran Crédits).

Le détail par fichier (titre original, auteur, page source, durée, usage suggéré) est dans `catalogue.csv` (séparateur `;`).

## Traitement appliqué
Conversion en mp3 mono 48 kHz, 96 kbit/s, volume harmonisé (loudnorm EBU R128 : musiques -20 LUFS, sons et jingles -16 LUFS, crête -1,5 dBTP), métadonnées supprimées. Aucune coupe.

## Sources
- OpenGameArt.org (recherche filtrée sur la licence CC0, licence revérifiée sur chaque page) : 29 auteurs, voir `catalogue.csv`.
- Kenney.nl (CC0) : Music Jingles (68 jingles Steel, Pizzicato, Sax, Hit), Sci-fi Sounds (explosions, bruits d'ordinateur), Impact Sounds (cloche).
- Les packs Kenney Interface Sounds et UI Audio sont déjà dans le jeu (`src/sons`) et ne sont pas repris ici.
